# ZeeSend API

The backend API for **ZeeSend**, a real-time messaging Android application.

## Overview

ZeeSend provides the backend services that support the ZeeSend Android client, including user-related operations and messaging functionality.

## ⚠️ Warning

This API was built several years ago when I was a complete beginner. It may contain security vulnerabilities and outdated coding practices, so **it is not recommended for production use**.

This repository is preserved as a learning resource for exploring early-stage backend development, understanding implementation decisions, and learning from past mistakes.

## Related Project

- **Android Application:** [ZeeSend](https://github.com/trtajim/zeesend)
